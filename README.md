# Викторина: Високосный год

Простая консольная игра-викторина на Java, которая проверяет знание правил високосных годов и количества дней в них.

## 🎯 Цель игры
Программа случайным образом предлагает год. Задача игрока:
1.  Определить, является ли предложенный год **високосным**.
2.  Ввести правильное **количество дней в этом году** (365 или 366).

За каждый полностью верный ответ (правильное определение високосности и верное число дней) начисляется одно очко. Игра продолжается до первой ошибки.

## 📋 Правила високосного года
Год является високосным, если он:
*   Делится на 4 **И** при этом НЕ делится на 100
*   **ИЛИ** делится на 400

## 🚀 Запуск программы
Для запуска программы необходим установленный **Java Development Kit (JDK)**.

1.  **Склонируйте репозиторий:**
    ```bash
    git clone https://github.com/MastaDimise/homeWork3.git
    cd homeWork3
    ```
2.  **Скомпилируйте Java-файл:**
    ```bash
    javac Main.java
    ```
3.  **Запустите программу:**
    ```bash
    java Main
    ```
